# Python CLI Mini-Projects

Acollection of my very first command-line interface (CLI) progarms built while learning Python fundamentals-covering loops, conditionals, functions, lists, dictionaries, and input validation.

## Projects Included
1. **Student Record Manager ('student_record_manager.py')** - Add student records, prevent duplicate roll numbers, calculate class averages, and find top scorers.
2. **CLI Banking System ('bsank_system_cli.py')** - Simulates basic account deposits, withdrawals with balance checks, and balance inquiries.
3. **Rock, Papers, scissors ('rock_paper_scissors.py')** - First-to-7 points match against the computer live score tracking.
4. **Dice Roll Simulator ('dice_roll_game.py')** - Simple interactive 6-sided dice roller.

## How to Run
Make sure you have Python 3 installed, then run any script from your terminal:
'''bash
python student_record_manager.py
